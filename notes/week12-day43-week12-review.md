## 知识地图（Day 40–42）

| 概念 | 一句话 |
|------|--------|
| HTTP | 一次请求 + 一次响应 |
| GET / POST | 查 / 提交新建 |
| 401 / 403 | 没登录 / 没权限 |
| 同源 | 协议 + 域名 + 端口相同 |
| CORS | 后端配 Allow-Origin；dev 用 proxy |
| 强缓存 | max-age 内不问服务器 |
| 协商缓存 | 问服务器；304 用本地，200 下新的 |
| Token | 登录拿 token → Authorization 带上 |

### 一句话串讲

> **GET 查 POST 交；401 登录 403 权限；跨域后端 CORS；强缓存不问、协商 304；Token 登录存、请求带。**

---

## 口述清单（15 分钟）

1. **401 和 403？** 401 没登录；403 登录了没权限
2. **跨域谁解决？** 浏览器限制；生产后端 CORS；dev proxy
3. **强缓存 vs 协商缓存？** 强缓存不问服务器；协商问变没变，304/200
4. **Token 鉴权流程？** 登录 → 存 token → Authorization → 401 跳登录
5. **Cookie Session vs Token？** Cookie 自动带、状态在服务器；Token 前后端分离常用

## 笔记区

### 今天最容易忘的一点

401 vs 403；强缓存（不问）vs 协商缓存（304 / 200）

### 口述自检（过/不过）

- HTTP 方法 + 状态码：**过** — GET 查、POST 提交；200 成功、400 参数错、401 未登录、403 无权限、404 找不到、500 服务器错（改数据常用 PUT/PATCH，没有 update 方法）
- CORS / 同源：**过** — 浏览器同源策略；后端 CORS / dev proxy；同源 = 协议 + **域名** + 端口
- 强缓存 / 协商缓存：**过** — 强缓存 max-age 内不问；协商在强缓存失效后问服务器，304 用本地、200 下新的
- Token 鉴权流程：**过** — 登录 → 存 token → 带 Authorization → 有效 200 / 无效 401 跳登录
