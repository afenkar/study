## HTTP 是什么（必背）

**HTTP** = 浏览器（客户端）和服务器之间传数据的**协议**。

一次交互 = **一次请求 + 一次响应**：

```
浏览器  ──请求 Request──▶  服务器
浏览器  ◀──响应 Response──  服务器
```

---

## 请求 Request（必背）

| 部分 | 干什么 | 例子 |
|------|--------|------|
| **URL** | 找哪个资源 | `/api/users?page=1` |
| **Method** | 什么操作 | GET / POST |
| **Headers** | 附加信息 | `Content-Type`、`Authorization` |
| **Body** | 提交的数据 | JSON `{ "name": "张三" }`（GET 通常没有 body） |

### 常用 Method

| Method | 干什么 | 典型场景 | 幂等？ |
|--------|--------|----------|--------|
| **GET** | 查数据 | 列表、详情 | ✅ 是 |
| **POST** | 新建 / 提交 | 登录、创建订单 | ❌ 否 |
| **PUT** | 整体更新 | 改整条记录 | ✅ 是 |
| **DELETE** | 删除 | 删一条数据 | ✅ 是 |

> **幂等**：同样请求发多次，结果一样（GET 查 10 次还是那份数据；POST 创建 10 次可能建 10 条）。

---

## 响应 Response（必背）

| 部分 | 干什么 | 例子 |
|------|--------|------|
| **Status Code** | 结果状态 | 200、404、500 |
| **Headers** | 附加信息 | `Content-Type: application/json` |
| **Body** | 返回数据 | `{ "code": 0, "data": [...] }` |

### 常见状态码（必背）

| 码 | 含义 | 什么时候 |
|----|------|----------|
| **200** | OK 成功 | 正常返回 |
| **301 / 302** | 重定向 | 跳转到新地址 |
| **400** | Bad Request | 参数错了、格式不对 |
| **401** | Unauthorized | **没登录** / token 无效 |
| **403** | Forbidden | 登录了但**没权限** |
| **404** | Not Found | 资源不存在 |
| **500** | Internal Server Error | 服务器内部挂了 |

### 401 vs 403（易错）

| | 401 | 403 |
|--|-----|-----|
| 意思 | 你是谁？先登录 | 我知道你是谁，但你不能看 |
| 前端常见处理 | 跳登录页 | 提示无权限 |

## 和前端的关系

```javascript
// axios / fetch 本质都是发 HTTP 请求
const res = await fetch('/api/users', {
  method: 'GET',
  headers: { Authorization: 'Bearer xxx' },
});
// res.status → 200 / 404 ...
// res.json() → 解析 body
```

Vue 项目里 Pinia / composable 调接口，底层全是 HTTP。

## 笔记区

### GET 和 POST 你怎么区分？（自己的话）

GET 查数据；POST 提交 / 新建（登录、创建）。改数据常用 PUT/PATCH。

### 401 和 403 你怎么记？（自己的话）

401 没登录 / token 无效；403 登录了但没权限。
