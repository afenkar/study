## 每日用法（固定）

1. 打开当日日程 → 对应题号  
2. **先闭卷口述 45–90 秒**（可录音）  
3. 再对照「标准答要点」纠偏  
4. 题目前的 `- [ ]` 改成 `- ✅`  
5. 口误/盲区写进该题「我的坑」一行  

**过关标准：** 抽查任意已勾题，能不看稿讲满 45 秒且无事实错误。
