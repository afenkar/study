## 每日用法

1. 打开 [`daily-plan.md`](./daily-plan.md) → 找到今天 Day  
2. 块 A Vue → 块 B 手写或项目 → 块 C 滚错题  
3. 在题库里勾 `- ✅`，在 daily-plan 底部勾当日 Day  

**过关标准：** 抽查已勾题，能不看稿讲满 45 秒且无事实错误；手写 P0 能闭卷写出。
